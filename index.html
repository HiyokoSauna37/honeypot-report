06

この観測について。

HOW IT WORKS
01 / 受け取る

架空のサイトがリクエストを受け取り、本文・判定情報・アップロードを非公開領域に保存します。

02 / 整理する

毎時30分にWindows端末から回収し、過去90日を重複排除。運用確認として識別できる通信は集計から除外します。

03 / 調べて公開する

既知ルールで分類し、新しい指標は確認後に公開。未特定の通信は後日、一次資料とAIを使って調べます。

集計範囲・制限・データの扱い

新しい観測期間より前のデータはこのページに含めません。旧ログは非公開で保管します。サインアウト中も回収できますが、Windows端末の電源とネットワークが必要です。

HTTP総数の内訳: Web攻撃の特徴 0 / 未分類 0 / 通常パス 0 / IoT等 0。通常パスでも、ルールで分からない攻撃が含まれる可能性があります。識別済み動作確認の除外: 0 件。

各一覧は最大100行。全件表示できないデータ: なし。公開前確認待ち: 0 件。本文参照 0 件 / 本文除外 0 件 / 解析不能イベント 6 件。

SQL、コマンド、テンプレート、外部URLは実行しません。システムファイルの応答は架空の固定データです。XSS入力は実行可能な形で返しません。アップロードは最大2MiBのリクエスト内で受け付け、公開せず隔離保存します。検出は限定されたパターンに基づき、見逃し・誤判定があり得ます。

接続元IP、Cookie、認証情報、本文・検体本体は非公開です。URLは無害化し、内部宛先や秘密情報らしい値を伏せます。本文やヘッダを暗号化した通信・未保存の本文は十分に判定できません。
